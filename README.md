# Sotto Authenticator

A project-aware authenticator for people managing work and personal accounts. This repository is the separate, open-source product within the `getsotto` organisation.

The first release is planned for native iOS and Android apps, with shared Rust authentication logic. Product scope and architecture are being developed in reviewable steps; see the internal engineering plan before treating this repository as release-ready.

## Status

Planning and initial engineering spike. No production authenticator is available yet.
